{% translate "Amazon Product Recommender (MIT IDSS – Capstone Project)" %}

{% blocktranslate trimmed %} As part of a capstone project from the Massachusetts Institute of Technology (MIT) Institute for Data, Systems, and Society (IDSS), this project developed a product recommendation system using a real-world dataset of Amazon product reviews. The goal was to design a recommender that improves customer engagement by suggesting relevant items based on user behaviour. {% endblocktranslate %}

{% blocktranslate trimmed %} The work began with cleaning and preprocessing the dataset — removing duplicates, handling missing values, and addressing sparse user–item interactions. Through exploratory analysis, cold-start issues were investigated and user and product activity distributions were examined, establishing minimum rating thresholds to reduce noise from infrequent interactions. {% endblocktranslate %}

{% translate "Multiple models were implemented and evaluated, including:" %}

  • {% translate "Rank-based recommender based on product popularity." %}
  • {% translate "User-based and item-based collaborative filtering with tuned similarity metrics." %}
  • {% translate "Matrix factorisation using SVD." %}
  • {% translate "A hybrid approach combining strengths of different models." %}

{% blocktranslate trimmed %} All models were evaluated using precision@k and recall@k. The final solution was an on-demand, deployable recommender using precomputed predictions for fast Streamlit inference. {% endblocktranslate %}
