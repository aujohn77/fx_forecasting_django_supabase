{% translate "Customer Personality Segmentation (MIT IDSS – Capstone Project)" %}

{% blocktranslate trimmed %} As part of a capstone project from the Massachusetts Institute of Technology (MIT) Institute for Data, Systems, and Society (IDSS), a customer segmentation system was developed using a retail dataset containing demographic attributes, purchase behaviour, campaign responses, and spending habits. {% endblocktranslate %}

{% blocktranslate trimmed %} The process began with data cleaning — handling duplicates, missing values, outliers, and inconsistencies — followed by univariate and bivariate analysis to explore patterns in customer behaviour. {% endblocktranslate %}

{% blocktranslate trimmed %} Features were engineered from purchase history, campaign responses, and household data, and several clustering algorithms were implemented and compared: {% endblocktranslate %}

  • {% translate "K-Means" %}
  • {% translate "K-Medoids" %}
  • {% translate "Agglomerative Clustering" %}
  • {% translate "Gaussian Mixture Models" %}

{% blocktranslate trimmed %} Silhouette scores, the elbow method, and cluster interpretability guided model selection. The final solution produced actionable customer profiles to support tailored marketing campaigns and retention strategies. {% endblocktranslate %}
