Trade CRM — Multi-Tenant SaaS CRM MVP

Trade CRM is a Django-based multi-tenant CRM MVP for trade/service businesses. It supports tenant signup, authentication, role-based permissions, clients, jobs, staff workflows, and a dynamic pricebook with custom fields.

Completed Features

  • Multi-tenant signup and tenant-scoped data isolation.
  • Session authentication with protected internal CRM pages.
  • Role-based permissions for owner, admin, manager, and staff users.
  • Client list, create, detail, and edit workflows.
  • Job list, create, detail, notes, and activity timeline.
  • Pricebook items, categories, item detail/edit, archive/unarchive.
  • Dynamic category-specific custom fields for pricebook items.
  • Demo warning banner and automated demo-data reset workflow.

In Progress / Missing Features

  • Quotes and invoices modules.
  • Advanced reporting and dashboard analytics.
  • Email/SMS notifications.
  • Production-grade subscription/billing layer.
  • More complete mobile-first UI refinement.

Tech Stack

  • Django, Django REST Framework, PostgreSQL / Neon.
  • Django templates, vanilla JavaScript, modular CSS.
  • Render deployment and GitHub Actions automation.

Architecture Highlights

  • API-first design: Django templates call backend APIs through JavaScript.
  • Service layer owns business logic, permissions, and tenant filtering.
  • Backend is the source of truth; UI visibility is not trusted for security.
  • Custom-field system allows category-specific pricebook data.

Security / Demo Sandbox

This is a public demo environment. Demo data is automatically reset every day. The repository is private because it contains a full SaaS-style implementation, but access can be provided on request.
